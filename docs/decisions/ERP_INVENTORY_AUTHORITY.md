# 库存权威与 ERP 同步方向

> 日期：2026-10-07 · 状态：历史业务方向记录。数量权威的实现归属已由同日[共用核心决定](SHARED_COMMERCE_CORE.md)取代；本文不作为新建 Inventory 私有数量账的依据。

## 已确认的决定

用户确认采用推荐分工：购物平台和网店产生销售后，由 Acuven Inventory 统一登记最小库存事实、计算库存变化，再将 Inventory 中的库存信息同步到 ERP。

- Acuven Inventory 是实物库存、销售占用、预留、安全库存、渠道份额和库存流水的权威来源。
- ERP 保存采购/经营/财务相关记录及同步得到的库存结果；ERP 余额不反向覆盖 Inventory。
- ERP 可提交经核实的实际收货等业务事实，Inventory 统一应用一次；同一批实物变动只有一个稳定事实引用。
- 原完整订单、顾客、资金和售后仍由 Shop、购物平台或其所属业务系统负责；Inventory 首期仍只管理库存所需的最小事件。

## 必须保持的数量语义

销售先减少可售量并建立销售占用；实际出库再同时减少实物在库和解除对应占用。取消和实际验收返库按既有库存规则处理；退款本身不加库存。ERP 同步不能再次触发同一销售/出库扣减。

## 后续技术设计范围

Inventory 事务保存库存变化与 ERP 出站待发送记录，异步同步稳定事实、SKU、变更结果和版本。ERP 暂时不可用时保留队列并重试，不让 ERP 接收成功成为 Inventory 完成库存事务的条件；这是后续待实施技术方案，不代表当前已经有 ERP 接口。

正式接入前仍须确定 ERP 产品及 API、SKU 对照、初始对账/导入、动作权限、事件/快照语义、重复和乱序处理、差异修复及恢复验收。改变本决定需重新审阅库存负责方及迁移设计。
