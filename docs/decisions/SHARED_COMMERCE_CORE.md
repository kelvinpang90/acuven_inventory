# 共用商品目录和基础库存账

> 日期：2026-10-07；部署边界更新：2026-10-08。系统群已确认唯一共用商品目录与库存账，并选定 `acuven_stock_core` 独立常驻服务；代码、数据库拓扑、接口、迁移和任务仍须设计评审。

依据为 Acuven Hub 的[商品与库存修订](../../../acuven_hub/REVISED_PRODUCT_STOCK_ARCHITECTURE_2026-10-07.md)，商品和库存主题以此优先于旧讨论及 Inventory 0.9 决定。

1. 商品身份由随相关模块交付的唯一逻辑目录维护。目录不单卖，不依赖 ERP 或门户产品的购买，增购模块不更换商品身份权威。
2. 实物数量、占用、预留及基础流水使用同一版本化库存核心；组合客户同一池只有一本有效数量账和写入入口。
3. Inventory 是可独立销售的多入口共享库存产品，提供渠道映射、份额、库存发布和差异对账；单卖随附目录与基础账，产品数据库不再另建权威余额。
4. ERP 管采购、成本及经营单据，经 Core 收货/自身销售；多个销售入口共卖一池需 Inventory。ERP 采购收货不计新增销售入口。
5. 渠道展示及实际价格各自维护；目录参考售价变更产生待确认建议，Inventory 连接器不自动获得完整商品发布范围。

[原库存权威决定](ERP_INVENTORY_AUTHORITY.md)保留历史。其“事实只登记一次、ERP 不反向覆盖或重复扣减”的意图继续成立；将数量权威实现固定在 Inventory 私有库、ERP 仅复制该账的部分由本决定取代。外部 ERP 适配器仍按明确来源、权限和退出规则设计。

具体对齐和技术未决闸门见[架构对齐](../HUB_ARCHITECTURE_ALIGNMENT.md)。`acuven_stock_core` 目前只有需求文档，独立服务尚未实现或部署，也不代表已批准跨仓库重构。
